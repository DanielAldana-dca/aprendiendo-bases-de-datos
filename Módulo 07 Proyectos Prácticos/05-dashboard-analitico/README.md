# 📊 Proyecto 05: Dashboard Analítico

Dashboard completo con métricas, KPIs y visualizaciones para el dataset de tienda.

## 🎯 Objetivos

- Dominar window functions
- Escribir CTEs complejas
- Crear vistas materializadas
- Optimizar consultas analíticas
- Diseñar un modelo OLAP

## 📋 KPIs del dashboard

### Ventas
- Ingresos totales (hoy, semana, mes, año)
- Crecimiento MoM y YoY
- Ticket promedio
- Número de pedidos
- Tasa de conversión

### Productos
- Top 10 más vendidos
- Categorías más rentables
- Stock bajo
- Productos sin movimiento

### Clientes
- Nuevos vs recurrentes
- Top clientes
- Cohortes
- Retención

### Operaciones
- Pedidos por estado
- Tiempo promedio de entrega
- Cancelaciones
